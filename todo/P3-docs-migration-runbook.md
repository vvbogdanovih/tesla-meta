## Проблема

План міграції даних зі старого сайту (WordPress+WooCommerce) розкиданий згадками по PRD, ADR-0002, db-schema §5, FR-A8 — окремого покрокового runbook немає, хоча без міграції каталогу запуск неможливий.

## Що зробити

Створити `docs/migration-runbook.md` з покроковим планом:
1. Експорт даних з WooCommerce (товари, категорії, зображення, метадані).
2. Дедуплікація за `sku` (за ADR-0002: товар — єдиний канонічний запис).
3. Мапінг на Car/ProductFitment (M2M) і глобальні категорії.
4. Перенесення зображень → R2 з конвертацією в AVIF (ADR-0007).
5. Заповнення таблиці Redirect (стара URL-структура → нова, ADR-0001).
6. Верифікація: кількість, вибіркове звіряння цін/залишків, перевірка редіректів.
7. Rollback-план.
