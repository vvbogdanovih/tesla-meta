## Проблема

У working tree два узгоджені change-sets (staged: «Monopay + лід-форми»; unstaged: «wishlist + price-sheet + isLive»), але до коміту є 5 неузгодженостей:

1. **ADR-0008**: тіло вже про 3 канали, а заголовок `# ADR-0008: … (IBAN / LiqPay)`, рядок у `docs/adr/README.md` і CLAUDE.md («0008 — … канали IBAN/LiqPay») — без Monopay.
2. **FRD §8 п.1**: «Вирішено: LiqPay» — суперечить власному FR-6.3 (LiqPay або Monopay) у тому ж staged-диффі.
3. **ADR-0011, «Пов'язано»**: посилається на неіснуючий FRD §3.12 — має бути §3.3a (FR-2.8–2.13).
4. **CLAUDE.md, рядок 17**: `adr/ # … (0000-template + 0001..0006)` — вже 0001..0012.
5. **FRD §6**: `product_images` без `is_live`; блоку `wishlist_items` немає; у примітці лишився привид старої архітектури `AND system_id = :sys`.

Також: версії/дати не підняті (FRD «v1.2, 27.06», db-schema «v1.1, 27.06»); `docs/README.md` каже «Draft v1.0» для PRD/FRD, реально v1.2.

## Що зробити

Виправити 5 пунктів + версії → два коміти за наявною staged-межею (Monopay+ліди; wishlist+price-sheet+isLive). **Коміт — лише з явної згоди користувача.**
