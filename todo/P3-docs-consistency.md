## 1. НП trigram GIN-індекси видалені, а docs стверджують протилежне
`db-schema.md §3` і коментарі в `schema.prisma` (~401, 416) обіцяють `np_cities_name_trgm_idx` / `np_warehouses_description_trgm_idx`. Реально: створені в міграції `20260702193211`, потім DROPPED у `20260704203115`. Пошук НП тепер без trigram (ймовірно ILIKE).
**Дія:** перевірити продуктивність автопідказок на 1000+ відділень → або відновити індекс, або оновити docs+коментарі схеми.

## 2. Шлях до Prisma-схеми застарів у docs
Docs посилаються на `prisma/schema.prisma`; реально — `src/database/prisma/schemas/schema.prisma`. Оновити db-schema.md та згадки в CLAUDE.md/todo.

## 3. Розбіжності FR ↔ реалізація (задокументувати або вирівняти)
- **FR-A5 «Ліди»** — специфіковано сайдбар-акордеон за типом (fitment/price_match/price_subscribe/contact); реально одна пласка сторінка `/leads` (бекенд не має фільтра за `type`, лише `status`/`q`).
- **FR-A4** — фільтр за статусом оплати та пошук за телефоном/email є на бекенді (ADR-0013), але не виведені в admin-UI (лише таби статусу + пошук за № замовлення).
- **FR-4.3/4.4** — `/search` це redirect на `/shop?q=`, без власного UI результатів/«нічого не знайдено»+форми підбору.
- **FR-5.4** — авторизований кошик у localStorage, не в БД (`API_URLS.CART` оголошено, не викликається; серверного cart-модуля немає). db-schema §5 допускає для MVP, FRD вимагає БД.
- **H1** — `/api/categories/:slug/products` — константа є, роут не підключений (еквівалент через `/catalog/products?category=`).

**Дія:** рішення по кожному — реалізувати або оновити FRD, щоб docs не суперечили коду.
