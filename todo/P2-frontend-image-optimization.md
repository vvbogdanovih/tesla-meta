# Зображення без оптимізації (unoptimized: true) — удар по LCP

- **Пріоритет:** P2 — важливий (Core Web Vitals / SEO)
- **Репозиторій:** tesla-frontend (+ tesla-backend)
- **Статус:** TODO

## Проблема

`next.config.ts` має `images.unoptimized: true` — жодного srcset/resize; у прайс-листі 44px-мініатюра тягне повнорозмірний файл, усі `sizes='...'` в коді — no-op. Це свідомий trade-off (коментар про VPS), але для e-commerce з сотнями карток прайс-лист із 50+ повнорозмірних фото на сторінку не пройде Core Web Vitals. Також `hero.mp4` (2.6MB) вантажиться без ліні.

## Де в коді

- `next.config.ts:7` — `unoptimized: true`
- `src/.../PriceSheet.tsx` (Thumb) — 44px мініатюра з повнорозмірним src
- ADR-0007 — бекенд уже конвертує в AVIF (sharp)

## Що зробити

Якщо Next-оптимізацію лишаємо вимкненою — генерувати thumbnail-варіанти на бекенді при аплоаді (ADR-0007 вже має sharp-пайплайн: додати розміри, напр. 100/400/800) і віддавати відповідний розмір у картках/прайс-листі. Альтернатива: увімкнути Next image optimizer, якщо VPS дозволить.
