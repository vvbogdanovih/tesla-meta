# Інтеграція з 1С (ADR-0016) не реалізована

- **Пріоритет:** P2 (Фаза 3 за дорожньою картою; але ADR-0016 — прийняте рішення без коду → розбіжність docs↔код)
- **Репозиторій:** tesla-backend
- **Статус:** TODO (виявлено 17.07.2026)

## Проблема

ADR-0016 та повне ТЗ `docs/integration-1c.md` описують обов'язковий контракт інтеграції, але **коду немає жодного**:
- немає pull-cron наявності/базової ціни у `Product.stockQty`/кеш;
- немає push замовлень у 1С після створення;
- немає ідемпотентності за `externalId`;
- **ні `Product`, ні `Order` не мають поля `externalId`** (ключ матчингу за ТЗ — `sku` + `externalId`).

Наразі `stockQty` змінюється лише вручну/сідом. Перед запуском із реальним складом — критично для актуальності наявності.

## Що зробити

1. Додати `externalId` у `Product`/`Order` (міграція).
2. Реалізувати pull-cron наявності+ціни (матчинг за `sku`), push замовлень (ідемпотентний за `externalId`), push статусу/оплати.
3. Site-agnostic контракт за `integration-1c.md` (1С — HTTP-сервер, сайт — клієнт).
4. Уточнити з користувачем пріоритет: реальний блокер запуску чи Фаза 3.
