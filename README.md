# Tesla Lviv — Meta Repository

Мета-репозиторій проєкту **Tesla Lviv** — інтернет-магазину оригінальних та аналогових запчастин Tesla для ринку України.

Цей репозиторій є **точкою входу** в проєкт: тут зберігається продуктова і технічна документація, опис архітектури та посилання на всі складові репозиторії. Код самих застосунків живе в окремих репозиторіях (див. [Структура проєкту](#структура-проєкту)).

---

## Про проєкт

Tesla Lviv — повний редизайн і перенесення наявного магазину (`teslalviv.com`, нині на WordPress + WooCommerce) на сучасний кастомний стек. Мета — сучасний адаптивний UX, повноцінна фільтрація і пошук по каталогу (понад 1000 SKU), вища продуктивність і конверсія, зі збереженням SEO-позицій при міграції.

Детальніше — у [Product Requirements Document](docs/PRD.md) та [індексі документації](docs/README.md).

## Структура проєкту

Проєкт організовано як набір репозиторіїв навколо цього мета-репозиторію:

| Репозиторій | Призначення | Стек | Статус |
|-------------|-------------|------|--------|
| **tesla-meta** (цей) | Документація, архітектура, координація | Markdown | active |
| `tesla-frontend` | Клієнтський застосунок | Next.js | scaffold (локально) |
| `tesla-admin` | Адмін-панель (окремий застосунок) | Next.js | scaffold (локально) |
| `tesla-backend` | Спільний backend API | NestJS · Prisma · PostgreSQL | scaffold (локально) |

Кожен застосунок — **окремий GitHub-репозиторій**. Локально вони живуть у `repos/` (ця тека в `.gitignore` — код застосунків не входить в історію tesla-meta).

### Стягнути застосунки

Один скрипт клонує (або оновлює) усі три репо в `repos/`:

```sh
./scripts/clone-repos.sh
```

За потреби можна перевизначити базу remote (SSH-аліас чи HTTPS):

```sh
REPO_BASE="git@github_vvbogdanovih:vvbogdanovih" ./scripts/clone-repos.sh
REPO_BASE="https://github.com/vvbogdanovih"      ./scripts/clone-repos.sh
```

## Дорожня карта (фази)

1. **MVP** — каталог + фільтри + пошук + картка товару + кошик + checkout + базова адмінка + міграція даних з WooCommerce.
2. **Фаза 2** — особистий кабінет з історією замовлень, лід-форми, блог, «Знайшли дешевше?», підписка на зміну ціни.
3. **Фаза 3** — VIN-підбір, інтеграції (ERP, розширена аналітика), оптимізації.

Деталізація — у [PRD, розділ «Орієнтовні фази»](docs/PRD.md#9-орієнтовні-фази).
