# ADR-0006: Rich text — TipTap, зберігання JSON + HTML

- **Статус:** Accepted
- **Дата:** 28.06.2026
- **Автори:** команда проєкту
- **Пов'язано:** [db-schema.md](../db-schema.md) · [FRD §3.4, §3.10](../FRD.md)

## Контекст

Опис товару та статті блогу потребують форматування (заголовки, списки, посилання, зображення). Треба обрати редактор і формат зберігання, який зручний для редагування й безпечний/швидкий для показу на сторфронті (SSR/SEO).

## Рішення

**Редактор — TipTap** (на ProseMirror): headless, стилізується під наші токени, React 19 / Next 16, зображення через R2-presign.

**Зберігаємо обидва представлення** (по два поля на сутність):

| Поле | Тип | Призначення |
|------|-----|-------------|
| `*_json` (напр. `descriptionJson`, `contentJson`) | `Json` | **Джерело правди.** TipTap-документ; вантажиться в редактор без втрат |
| `*_html` (напр. `descriptionHtml`, `contentHtml`) | `text` | **Похідне.** Згенерований і санітизований HTML — віддається клієнту для SSR/SEO |

**Потік:**
1. Адмінка редагує → надсилає на бекенд **JSON** документа.
2. Бекенд генерує HTML з JSON (`@tiptap/html` + ті самі extensions) → **санітизує** (`sanitize-html`, whitelist) → зберігає **обидва** поля.
3. Сторфронт по запиту отримує **готовий HTML** → SSR `dangerouslySetInnerHTML` (швидко, без конвертації на клієнті).

HTML завжди **похідний від JSON на сервері** — тож консистентний і завжди санітизований (клієнт не може підсунути довільний HTML).

## Наслідки

- ✅ Редагування без втрат (JSON), показ швидкий і SEO-дружній (готовий HTML).
- ✅ Безпека: HTML генерується/санітизується лише на бекенді.
- ⚠️ Дублювання даних (JSON + HTML) — прийнятна ціна; HTML регенерується з JSON при кожному збереженні.
- ⚠️ Набір TipTap-extensions має бути **однаковий** на адмінці (редактор) і бекенді (generateHTML) — винести у спільний конфіг.
- Застосунки: `descriptionJson/Html` (Product), `contentJson/Html` (BlogPost) — див. [db-schema.md](../db-schema.md).
