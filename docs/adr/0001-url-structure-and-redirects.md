# ADR-0001: Структура URL та стратегія редиректів

- **Статус:** Proposed *(очікує підтвердження індексації в Google Search Console)*
- **Дата:** 27.06.2026
- **Автори:** команда проєкту

## Контекст

Чинний сайт `teslalviv.com` (WooCommerce) використовує URL виду:
- категорія: `/product-category/model-3/`
- підкатегорія: `/product-category/model-3/kuzov-model-3/`
- товар: `/product/[slug]/`

FRD §2 пропонує чистішу структуру: `/category/[model]`, `/category/[model]/[system]`, `/product/[slug]`.

Зміна структури URL зазвичай вимагає карти 301-редиректів і несе ризик тимчасової просадки позицій. **Але** є суттєва обставина: реклама на сайті не запускалась, і за попередньою перевіркою (`site:teslalviv.com` без результатів) сайт, ймовірно, **майже або зовсім не проіндексований**. Реклама й індексація незалежні — індексація відбувається через Googlebot за наявності sitemap/robots (вони є), тож остаточну відповідь дасть лише **Google Search Console (Coverage)**.

## Розглянуті варіанти

- **A. Зберегти чинні URL** (`/product-category/...`). Нульовий ризик для SEO, але менш чисті URL і збереження нетипових slug-ів (Highland = `model-3-jan-2024`).
- **B. Нові чисті URL + повна карта 301.** Краща структура; за наявності індексації — керований ризик через 301.
- **C. Нові чисті URL без редиректів.** Можливо лише якщо проіндексованого контенту немає.

## Рішення

Обрано **нові чисті URL** (структура з FRD §2). Стратегія редиректів — **залежно від індексації**:

- Якщо GSC підтверджує **відсутність значущої індексації** → варіант **C**: чисті URL без карти 301 (або мінімальна карта лише для поодиноких проіндексованих URL). Ризик G4 ≈ 0.
- Якщо є проіндексований контент/трафік → варіант **B**: повна карта 301 (1:1, без ланцюгів) зі старих URL на нові.

Slug-и товарів зберігаємо в будь-якому разі (SEO-актив). Highland/Juniper отримують осмислені slug-и (`model-3-highland`, `model-y-juniper`).

## Наслідки

- **Позитивні:** найчистіша структура з першого дня; за відсутності індексації — без редиректного боргу й ризику.
- **Негативні / ризики:** рішення **заблоковано** до перевірки GSC; якщо індексація виявиться значущою — потрібна повна карта 301 і моніторинг просадки.
- **Передумова:** підтвердити канонічний домен (`teslalviv.com` vs наявний `teslalviv.com.ua`).
- Впливає на: [FRD §2 (sitemap/URL)](../FRD.md#2-перелік-сторінок-sitemap), [NFR-3 (міграція URL)](../FRD.md), [SEO-стратегію §2.1](../seo-strategy.md).

## Подальші дії

1. Перевірити Coverage у Google Search Console → зафіксувати кількість проіндексованих сторінок.
2. Підтвердити канонічний домен.
3. Оновити статус ADR на **Accepted** з обраним варіантом (B або C).
