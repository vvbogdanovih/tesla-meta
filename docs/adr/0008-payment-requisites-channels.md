# ADR-0008: Реквізити продавця та канали оплати (IBAN / LiqPay / monopay)

- **Статус:** Accepted
- **Дата:** 29.06.2026
- **Автори:** команда проєкту
- **Пов'язано:** [db-schema.md](../db-schema.md) · [FRD §3.7](../FRD.md) · [ADR-0015](0015-monopay-online-payment.md) (monopay-канал: потік оплати)

## Контекст

Продавець має керувати тим, **на кого приймаються кошти** (банківські реквізити для оплати за IBAN) і **через який акаунт LiqPay** проходить онлайн-оплата. Можливі кілька юр-осіб (ФОПи). Ключі LiqPay і реквізити — чутливі дані.

## Рішення

Окрема сутність **`PaymentRequisite`** (`payment_requisites`), керує **лише superadmin**:

- Поля: `label` (ПІБ отримувача — **рівно 3 слова**), `taxId` (ІПН/ЄДРПОУ), `iban`, `bankName`, `liqpayPublicKey`, `liqpayPrivateKey`, `monopayToken` (токен monobank-еквайрингу).
- **Три незалежні канали оплати** з окремими прапорцями: `ibanActive`, `liqpayActive`, `monopayActive`. Активним по кожному каналу може бути **лише один** запис (активація гасить інші в межах свого каналу).
- **Валідація активації:** IBAN-канал вимагає ПІБ+ІПН+IBAN+банк; LiqPay — обидва ключі; Monopay — токен. Неповний канал активувати не можна.
- **Авто-активація:** канал вмикається автоматично, коли він стає повним і ще немає активного по цьому каналу (зокрема перший доданий реквізит). Подальше перемикання — кнопками у списку (у формі прапорців активності немає).

### Безпека секретів

- Секрети `liqpayPrivateKey` і `monopayToken` зберігаються **зашифрованими** (AES-256-GCM, ключ із `PAYMENT_ENC_KEY`).
- У відповідях API ключ **ніколи не повертається** — лише прапорці `liqpayPrivateKeySet` / `monopayTokenSet`. Оновлення — write-only (порожнє значення = не змінювати).
- Доступ до модуля — **тільки superadmin**; розшифрування — внутрішнє (для платіжного потоку), не через контролер.

## Наслідки

- ✅ Гнучке керування отримувачем коштів і LiqPay-акаунтом; кілька ФОПів.
- ✅ Секрети не витікають у відповідях; шифрування at-rest.
- ⚠️ `PAYMENT_ENC_KEY` має бути надійним і незмінним у проді — зміна ключа зробить збережені приватні ключі нечитабельними (ввести заново).
- ⚠️ Онлайн-еквайринг — **LiqPay та Monopay** (monobank), окремі канали; інших провайдерів — через адаптер.
